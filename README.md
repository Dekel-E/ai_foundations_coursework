# AI Foundations and Applications - Coursework

This folder contains homework assignments and code for the AI Foundations and Applications course (960210) at the Technion, 2025/2026.


## Course Objectives

This course covers the fundamental concepts and computational methods of artificial intelligence, including problem solving, search strategies, planning, learning, and logical reasoning.

## Course Topics

1. **Introduction** - Overview of AI goals and applications
2. **Systematic Search Methods** - Basic search algorithms
3. **Heuristic Search** - Evaluation functions, A* algorithm, heuristic design
4. **Planning with Uncertainty** - Markov Decision Processes
5. **Learning from Feedback** - Q-learning and reinforcement learning
6. **Game Playing** - Alpha-beta pruning, MCTS, UCT
7. **Logical Inference** - Syntax and semantics, model theories
8. **Proof Theory** - Resolution as a proof theory for propositional logic
9. **Constraint Satisfaction** - CSP problems, tree search and tree width

## Folder Structure

Each homework assignment has its own folder:
- `hw1/` - First assignment
- `hw2/` - Second assignment 
- `hw3/` - Third assignment 

Each assignment folder contains:
- Implementation code
- Test files and validation scripts
- Documentation and notes

## Getting Started

To work on assignments:
1. Navigate to the assignment folder (e.g., `hw1/`)
2. Read the assignment requirements
3. Implement solutions in the provided files
4. Run tests to verify your implementation
5. Check your code against the provided validation scripts
